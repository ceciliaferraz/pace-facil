# PaceFácil

Ferramenta web simples, rápida e responsiva para calcular o *pace* (minutos por quilômetro) e a velocidade exata na esteira para corredores.

## Acesse Online
Você pode testar a aplicação direto no navegador através do link:
[Acesse o PaceFácil aqui](https://ceciliaferraz.github.io/pace-facil/)

## Sobre o Projeto
Desenvolvido para resolver uma dor real de corredores amadores e praticantes de esteira que precisam calcular rapidamente suas metas de tempo, distância e ritmo de prova sem complicação.

## Tecnologias Utilizadas
* **HTML5** (Estruturação)
* **CSS3** (Estilização e design responsivo)
* **JavaScript** (Lógica de cálculo e manipulação do DOM)
* **GitHub Pages** (Hospedagem e deploy contínuo)
